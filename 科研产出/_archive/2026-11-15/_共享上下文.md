## 2. 开题报告核心内容（已提取为文本）

- 论文题目：**基于知识图谱的大语言模型自动生成高性能算子代码方法研究**
- 研究内容（6 步）：
  1. 高性能算子代码库预处理（OpenBLAS 等，静态分析截取核心计算片段）
  2. 基于多层次 Agent 的代码知识深度解析（算法级 / 代码级 / 指令级三层，输出 JSON）
  3. 高性能计算优化知识图谱构建（自定义 Schema；实体如"计算流程""优化策略""硬件特征"；Milvus 向量库）
  4. 知识融合与对齐（粗筛聚类 + LLM 精细判别，实体合并、关系重定向）
  5. 优化策略推荐（提取用户代码"计算流程"→ 向量检索相似计算流程 → 关联优化策略 → 打分排序）
  6. 基于结构化 Prompt 模板的代码优化（模板注入计算流程特征、策略实施步骤、硬件参数、可调参数区间 → LLM 生成优化代码）
- 三个创新点：
  1. KG+LLM 融合 + 多层次 Agent 解析（算法/代码/指令三维挖掘隐性优化知识）
  2. 两阶段实体对齐（向量粗筛 + LLM 判别）
  3. 结构化 Prompt 模板（计算流程特征 + 硬件约束 + 优化步骤，减少幻觉）
- 难点：Schema 设计、实体对齐与融合、基于 LLM 的精准检索与策略描述生成。
- 工作量/进度：1 个月建样本库；2-4 月 Schema+Agent 建图；5-8 月对齐+检索+推荐；10-12 月实验+论文。

## 7. 关键判断线索（Lead 初步观点，供批判）
