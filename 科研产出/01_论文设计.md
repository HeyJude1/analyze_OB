# 论文设计

沿用开题题目《基于知识图谱的大语言模型自动生成高性能算子代码方法研究》。绪论将本文问题限定为 **给定通用 C 算子实现、接口契约和目标硬件，能否用专家知识减少不适用的优化选择，并在同等生成和测量预算下提高正确且加速的比例**。

## 两项主要贡献

| 研究工作 | 方法 | 判据 |
| --- | --- | --- |
| 条件化优化知识构建 | 从配对专家实现提取源代码事实，统一优化动作，把策略概念与具体实现、语义前提、ISA 要求、收益条件和证据分开 | 标注样本中，策略、条件和出处可核实。对齐应减少重复，同时保留跨工具链和跨架构的实现差异 |
| 约束引导的策略组合与代码生成 | 按任务特征选策略，检查适用性，推导参数候选，按先后依赖和资源限制组合，再交给 LLM 和执行器 | 同卡片、同预算条件下，完整方法较独立卡片推荐减少无效计划，或提高正确且加速的比例。留出任务单独验证 |

开题中算法、代码、指令三个视角用于描述知识来源。两阶段实体对齐作为构建方法的一部分，结构化 Prompt 作为优化计划与生成器之间的接口。计划可将失败定位到条件、实现模板或参数，待静态系统完成后，再比较静态知识、文本经验追加、条件与参数修订三个版本。

最接近的对照各自覆盖论文的一部分。[QiMeng-TensorOp](https://ijcai.org/proceedings/2025/783) 已有硬件原语生成和调参，[PRAGMA](https://arxiv.org/html/2511.06345v2) 已将 profiling 纳入生成闭环，[KOPE](https://arxiv.org/html/2608.25570) 已有优化经验图及 RISC-V 迁移实验。因此本文将增量落实到**专家实现中提取的条件、作用区域和变体关系，如何转化为目标平台的可验证方案**。以本文的强对照检验这项增量。

## 数据范围

| 角色 | 算子 | 选用理由 |
| --- | --- | --- |
| 首批建图与功能验证 | DAXPY、DDOT、DGEMV、DGEMM | 分别覆盖逐元素更新、向量归约、矩阵向量乘、矩阵乘。知识来源使用对应专家代码，生成输入使用可重编译的通用 C |
| 主实验留出候选 | DSCAL、DASUM、DSYMV、DSYMM | 检验逐元素、归约和结构矩阵的复用。DSYMM 与 DGEMM 的共享微内核按近迁移单列 |
| 外部领域留出 | 一维卷积 | 检验连续访存、分块和尾部处理能否复用。卷积边界、滑动窗口和输入输出长度由任务契约明确 |
| 后续扩展候选 | DNRM2、DTRMM、FFT | DNRM2 检验数值稳定性，DTRMM 检验三角依赖。FFT 需先冻结复数布局、方向、归一化、长度与置换语义 |

选用一维卷积是本轮范围决定。它在同一套 C 接口、CPU 工具链和数值验证框架下可快速形成完整任务，也能测试图谱能否处理不同的访存模式。外部留出的优化代码仅用于评测或对照，初始建图排除它。

## 章节与证据

| 章节 | 需要交出的证据 |
| --- | --- |
| 第 1–2 章 绪论和相关工作 | 从实际案例说明单靠文本相似度可能推荐错误架构或布局。用最邻近工作界定论文差异 |
| 第 3 章 优化知识构建 | 可复建语料清单、配对例子、分层证据、审核样本、字段级质量、实体对齐误差 |
| 第 4 章 知识引导生成 | 标出真实任务、条件判定、参数与计划的输入输出。给出至少一个合法组合和一个被拒绝的组合 |
| 第 5 章 实验 | 正确性、实际性能、成本、条件与组合消融、跨架构和跨算子迁移、典型错误与回退 |
| 第 6 章 结论与扩展 | 总结成立的条件和未覆盖的范围。反例更新试点和 GPU 结果可在有充分数据时扩展 |

工作量主要来自四类可复现产物。它们是有明确 ABI 和数值检查的多平台算子、带可核实来源的优化知识、能输出完整决策轨迹的生成方法，以及真实对照和留出实验。论文分别提供源码、知识质量和性能证据，不以模型调用次数或图规模代替方法效果。
