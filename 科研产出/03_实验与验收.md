# 实验与验收

主实验在 x86 和 RISC-V 各自比较同语义实现，同一平台内以适配目标 ISA 的单线程 C `-O3` 为性能分母。OpenBLAS 是专家参照，正式计时使用相同调用层次。卷积使用同契约的手写实现和有限预算的参数搜索参照。泰坦 GPU 若纳入，在确认具体型号和工具链后另设 CUDA 小案例。

## 公平对照

| 方法 | 输入和执行 | 回答的问题 |
| --- | --- | --- |
| 无外部知识 | 任务、通用 C、目标硬件、共同修复协议 | 生成器自身能做到什么 |
| 文本 RAG | 同一批卡片的字段、自然语言或单层文本序列，按内容检索并用已知任务和硬件元数据过滤 | 同源文本检索能带来多少收益 |
| 结构化策略卡 | 同样的卡片、适用性谓词、合法参数或候选值，卡片独立排序 | 结构化知识和条件过滤有多大贡献 |
| 约束规划 | 增加跨卡片关系、参数实例化和组合方案 | 组合与目标参数选择能否在同预算下带来增量 |

四组固定模型版本、代码和基本提示、输出上限、最大修复次数与执行预算。三组有知识的方法共享卡片内容、模板和条件字段，附加知识使用同样的上下文上限，并保存实际 token、选中的卡片 ID 和截断记录。无 LLM 参数搜索与编译器、专家库作为另外的参照。为分清组合和参数的增量，对关键算子再做“只去关系”和“只关实例化”消融。

## 实验矩阵

| 实验 | 采样与比较 | 主要证据 |
| --- | --- | --- |
| 知识准确性 | 分层审核源码片段、策略、条件及对齐对 | 字段级 P/R/F1、错误合并率、溯源可复核率、可达率 |
| 四方法主实验 | 首批核心四算子验证后扩至八个算子 × 两平台 × 四方法 × 三次独立生成，共 192 份目标程序 | 功能正确率、正确且提速比例、固定任务集合速度、生成和执行成本 |
| 跨算子 | 知识图谱按白名单从训练来源重建，仅将目标通用代码和任务契约交给生成器。单列 SYMM 近迁移 | 留出算子上的正确率和速度，查看使用的知识出处 |
| 跨架构 | 固定目标任务和硬件，比较复用原配置、按目标重算、加入少量目标开发经验 | 负迁移率、参数可行率、搜索成本、最终速度 |
| BLAS 之外 | 一维卷积作为外部留出，保持相同的方法和硬件设置 | 兼容性、正确性、性能与迁移路径。解释哪些模式能迁移 |
| 反馈维护试点 | 开发集相同轨迹下，比较静态、文本追加与条件更新，再用隔离回归集和最终评估集 | 条件准确率、坏更新回归率、收益和维护成本 |

每份生成物应支持一组尺寸，任务需要尺寸特化时，各方法采用相同任务定义并单列。正式留出隔离使用源码哈希、共享实现路径、别名及派生知识溯源检查。模型的预训练覆盖是外部效度限制。迁移实验在目标知识排除版本上单独运行，且不会使用留出集挑超参数。

## 任务和真机协议

1. 冻结任务接口、有效步长／布局、重叠规则、输出语义、数值容差和候选验证预算。准备随机、极小、非倍数尾部、不规则矩阵、特殊 alpha/beta 以及适用的步长和数值范围。用与候选独立的参考，给写入区域加边界检查。
2. 确认 x86 CPU、RISC-V SoC、ISA 和矢量版本、编译器、线程和运行环境。用板上探针确认 VLEN 与所需 FP64 指令。交叉构建结果、QEMU 结果、真机结果独立记录。
3. 固定线程和绑核。用缓存内、跨缓存、大工作集与不规则形状覆盖性能区域。先预热，再成组交替测各实现，用单调时钟和足够长的批次。记录温度、频率、编译参数、计时数据、失败状态和源码指纹。矩阵乘主表计完整调用，包括需要的打包。预打包微内核可另制表。
4. 性能主指标包括正确且加速比例、固定共同通过集合的几何平均加速比和样本覆盖率。阈值在试运行中根据基准重复测量确定，可从 1.05 倍作为试验值。报告首轮与修复后正确率、全部失败、token、编译和测量次数。置信区间按算子或同源任务聚类，重复计时用于估计噪声。将整体增益归因到某条策略需要单策略对照或相应消融。

第一阶段准备了五个算子的 120 个配对输入，并通过 DGEMM 离线回放复核接口。第二阶段扩充至九个算子，以同一模型在两个目标和四种方法上完成 72 个单次重复单元。首轮与修复后数值正确率和失败原因已归档。正式多次重复、独立测试和真机性能待开展。[九算子功能对照](experiments/thesis/functional_2026-11-19/README.md) · [论文项目进展](04_论文项目进展.md)
